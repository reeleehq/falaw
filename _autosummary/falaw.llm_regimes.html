falaw.llm_regimes#

Token-rate regimes: the one vocabulary both falaw LLM rate tables price in (falaw#128).

falaw.llm_prices (first-party calls) and falaw.llm_rates (calls routed through fal’s any-llm) both bill a model’s tokens at a set of per-million rates, and some models switch to a dearer set once a prompt passes a length threshold. This module owns that shape (LlmPriceRates), how a table row spells it (rates_from_row(), parse_long_prompt()) and which set a prompt is billed at (rates_for_prompt()), so neither table keeps its own copy.

>>> base = LlmPriceRates(input_usd_per_mtok=1.0, output_usd_per_mtok=2.0)
>>> long = LlmPriceRates(input_usd_per_mtok=3.0, output_usd_per_mtok=4.0)
>>> rates_for_prompt(base, 100, long_prompt_over_tokens=100, long_prompt_rates=long) is base
True
>>> rates_for_prompt(base, 101, long_prompt_over_tokens=100, long_prompt_rates=long) is long
True
